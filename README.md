# 返済計画シミュレーター

`index.html` をブラウザーで開いて利用できます。借入先ごとに元金残高・年利・毎月の定額返済額・追加返済額と、任意の返済開始月・完済目標月を入力し、「返済の見通しを立てる」を押すと最大5件の元金推移と完済見込みを比較できます。開始月が未設定の場合は今月を基準にします。目標月を設定すると、目標月に間に合わせるための月々の追加返済額も試算します。条件を変更した場合は、ボタンを押して見通しを更新します。入力内容は保存・送信されません。

計算は月次の簡易試算です。各月の利息を月初残高 × 年利 ÷ 12（1円単位で四捨五入）で求め、月末に定額返済と追加返済を充当します。実際の返済額や利息は金融機関の計算方式・返済日等で異なります。
